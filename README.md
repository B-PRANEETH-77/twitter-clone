# X (Twitter) Clone

A static frontend recreation of the X (formerly Twitter) home page, built using HTML and Tailwind CSS.

## Features

- Responsive three-column layout
- Navigation sidebar with icons
- Home feed with sample posts
- Post composer interface
- Trending topics and suggested accounts
- Tailwind CSS styling

## Tech Stack

- HTML5
- Tailwind CSS
- Google Material Symbols

## Getting Started

1. Clone this repository.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Build the CSS:

   ```bash
   npm run build
   ```

4. Open `index.html` in your browser.
